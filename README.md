# 🎵 Pink Island Player — Прозрачный Аудиоплеер в стиле Dynamic Island (Rust + iOS Glass)

> Стильный десктопный плеер-островок в эстетике **Apple Dynamic Island** с **абсолютной прозрачностью (без белого фона и рамок)**, неоновыми розовыми акцентами, скрытый из панели задач и работающий в **системном трее Windows** с автозапуском.

---

## ✨ Ключевые возможности

1. **Абсолютная прозрачность (Zero White Box)**:
   - Полное попиксельное альфа-смешивание (32-bit ARGB).
   - Белый прямоугольный фон полностью убран — на рабочем столе отображается исключительно аккуратная полупрозрачная капсула-островок с мягким розовым свечением.

2. **Чистая панель задач (Без лишних иконок)**:
   - Приложение работает в режиме системного оверлея (`WS_EX_TOOLWINDOW`).
   - Иконка **не занимает место на панели задач Windows**.

3. **Системный трей (System Tray возле часов)**:
   - В трее Windows отображается розовая иконка с музыкальной нотой.
   - Двойной клик или левый клик по иконке: мгновенно **скрывает / открывает** плеер.
   - Меню по правому клику:
     - 🎵 **Показать / Скрыть плеер**
     - 📌 **Закрепить открытым**
     - 🧭 **Положение на экране:** Справа (по умолчанию), Сверху (Dynamic Island), Слева, Свободное перемещение
     - ⚡ **Автозагрузка при старте Windows** (галочка вкл / выкл)
     - ❌ **Выход**

4. **Автозапуск Windows (Startup)**:
   - Автоматически прописан в официальный реестр автозапуска `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\PinkIslandPlayer`.
   - При включении компьютера плеер стартует бесшумно в фоне.

5. **Dynamic Island физика и анимация (iPhone)**:
   - **Свернутое состояние (Капсула 230x46px)**: круглая обложка, бегущая строка с треком и 4 анимированные розовые полоски мини-эквалайзера.
   - **Раскрытие по наведению мыши**: плавно разворачивается в полноценную карточку (380x220px) с 24-полосным розовым аудио-эквалайзером, HD-обложкой, таймлайном с перемоткой и кнопками управления.
   - **Авто-сворачивание**: плавно сжимается обратно через 350мс после ухода курсора.
   - **Перетаскивание (Drag & Drop)**: зажмите левую кнопку мыши и перетащите островок в любое место любого монитора.

6. **Нативное Rust-ядро (GSMTC Windows)**:
   - Скомпилированный бинарник [`pink_core/target/release/pink_core.exe`](file:///d:/Move%20Folder/pink_core/target/release/pink_core.exe) (1.8 МБ).
   - Перехватывает треки из **Spotify**, **Яндекс.Музыки**, **VK**, **YouTube**, **Google Chrome**, **Telegram**, **AIMP**, **VLC** в реальном времени.

---

## 🚀 Запуск

* **[`start_player.vbs`](file:///d:/Move%20Folder/start_player.vbs)** — тихий запуск в один клик без консольных окон.  
* *или* **[`start_player.bat`](file:///d:/Move%20Folder/start_player.bat)**

При первом запуске плеер автоматически активирует автозагрузку Windows, размещает иконку в системном трее и появляется у правого края экрана.
