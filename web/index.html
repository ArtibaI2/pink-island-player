Создан для максимального комфорта

Никаких тяжелых процессов в памяти. Только легкое, мгновенное нативное приложение.

🦀

Нативное ядро Rust (1.8 МБ)

Прямое подключение к Windows Media Transports Control (GSMTC) и Storage Streams. Мгновенное извлечение HD-обложек альбомов и статуса трека.

💎

Чистое матовое стекло (32-bit ARGB)

Попиксельная прозрачность без белых фонов и артефактов. Только скругленная капсула Dynamic Island с неоновым розовым ореолом.

🔔

Системный трей и чистый Taskbar

Не захламляет панель задач Windows. Плеер аккуратно живет в системном трее рядом с часами с быстрым контекстным меню.

📊

24-полосный живой спектрограф

Динамические частотные волны в розово-малиновом градиенте, пульсирующие в реальном времени под ритм играющей музыки.

⚡

Автозапуск со стартом Windows

Встроенная интеграция в реестр автозапуска. Стартует бесшумно в фоне и готов к работе в ту же секунду, когда заиграет музыка.

🧲

Пружинная физика Apple (Spring Easing)

Плавное морфирование из тонкой капсулы в развернутую карточку за 280мс с кривой сглаживания cubic-bezier(0.16, 1, 0.3, 1).
